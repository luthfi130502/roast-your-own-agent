# Roast Your Own Agent

My entry for the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068):
one line, at most 200 characters, roasting my own AI agent — the one that
finishes tasks in its plan, its progress updates and its cheerful summary
long before the code hears about it.

## Run

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt`. The script checks the
gate itself before and after writing: exactly one line, 1–200 characters,
UTF-8, not blank. No dependencies beyond the Python 3 standard library.
